# T0 — Priority plant list (MVP: 50 common houseplants)

Companion doc for spec #7 (research: open plant datasets & licensing). This is the
reference list of 50 common houseplants the MVP dataset must cover.

Numbers are for reference only — **not a ranking**. The first 10 are the priority
plants from the MVP issue (#9 "Priority List"); rows 11–50 are additional
widely-grown common houseplants.
